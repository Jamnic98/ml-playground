# ml-playground

Welcome to **ml-playground**, a personal repository for experimenting with machine learning (ML) and data science (DS) concepts, algorithms, and workflows. This space is designed to explore everything from foundational ML models to more advanced projects, including end-to-end data pipelines, model evaluation, and deployment experiments.

## 🚀 Purpose

The goal of this project is to:

- Sharpen practical machine learning and data science skills
- Experiment with different ML algorithms and techniques
- Analyse and visualise real-world datasets
- Test ideas related to feature engineering, model optimisation, and interpretability
- Build small, focused projects for learning and portfolio purposes
